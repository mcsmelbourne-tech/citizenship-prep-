# U.S. Citizenship Test Preparation App

An interactive web application built with Streamlit to help applicants prepare for the U.S. Naturalization process.

## Features:
- **N-400 Application Review:** Key definitions and background questions.
- **Civics Practice Test:** Flashcards and random mini-quizzes covering the 100 civics questions.
- **Reading & Writing Practice:** Random sentence generators for language testing.
- **Interview Tips:** Essential guidance for field office appointments.
